## <img src="https://api.iconify.design/lucide/microscope.svg?color=%236D28D9" width="26" align="top" alt=""/> About me

I'm a researcher-minded builder — I'd rather understand a new domain deeply enough to ship something real in it than stay comfortable in one stack. That's why my repos swing between industrial firmware, on-device AI, and full-stack web apps: each one was picked up for a hackathon or a problem worth solving, not because it matched the last one.
